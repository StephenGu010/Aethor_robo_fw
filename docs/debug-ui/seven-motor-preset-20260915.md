# ID1～7 同型号电机调试预置

用户确认ID1～6与现有ID7均使用相同S3519电机、驱动器及Gr=19.2032。本次把既有ID7台架契约扩展为七台同型号电机的预置，不修改ARM_PRODUCTION的逐轴机械标定与使能要求。

| 电机ID | Master ID | LCD位置换算比 | 默认速度 | LCD Kp / Kd |
|---|---|---|---|---|
| 1 | 0x11 | 19.2032 | 10°/s | 80 / 0.2 |
| 2 | 0x12 | 19.2032 | 10°/s | 80 / 0.2 |
| 3 | 0x13 | 19.2032 | 10°/s | 80 / 0.2 |
| 4 | 0x14 | 19.2032 | 10°/s | 80 / 0.2 |
| 5 | 0x15 | 19.2032 | 10°/s | 80 / 0.2 |
| 6 | 0x16 | 19.2032 | 10°/s | 80 / 0.2 |
| 7 | 0x17 | 19.2032 | 10°/s | 80 / 0.2 |

LCD输入/显示位置为输出轴角度，打包位置为转子弧度；速度字段沿用ID7的输出轴单位。LCD Kp下发时除以19.2032，Kd不变。POS固定终点、MIT本地轨迹、0.5°输出轴到位容差、3.5 Nm反馈停止门限、1°角度和1°/s速度步进沿用当前实现。3.5 Nm是软件反馈保护阈值，不是瞬时限流。

LCD构建目标显式选择七电机通信兼容预置：FC/FD/FE/FB特殊命令发送到基础ESC ID，POS运动数据仍使用0x100+ESC ID。原默认构建及旧单ID7配置保留兼容。

每台电机的POS/MIT范围只取本次发现的PMAX、VMAX和MAX_SPD，分别形成独立profile。本次尚未发现、身份/模式/量程不完整或非法时，profile无效，不伪造反馈；仅发现ID7不能让ID1～6就绪。已发现后的空闲旧反馈与原ID7一样保留历史信息，实际执行前仍需新的失能反馈；缓存的profile不代表电机当前在线。参数或验证状态变化使该台已预览的旧请求失效。

默认首页目标仍为ID7，不自动发现全部电机或执行运动。连接新电机时，驱动器需事先设置对应ESC/Master ID。先在USB串口执行 `1 bench init 1`（初始化ID1；末尾数字换成当前接入的目标ID，后续请求使用新的非零编号），再到LCD电机列表选择该ID，返回首页申请本地控制，完成松键后长按确认，随后进入该电机的POS/MIT操作。LCD“控制检查”显示检查结果，本身不会执行电机初始化。

若此前持有另一台电机的本地控制，应先失能、释放本地控制，再进行新目标的USB初始化与选择。七台全部接入并确认ID无重复后，可用 `2 bench init 1,2,3,4,5,6,7` 初始化实际已连接的整组；不要把仍未连接的ID加入这条初始化命令。每次LCD调试仍只操作一个目标。新增预置不代表ID1～6已做过实机验收，也不等于七轴整臂控制配置已经标定。

实现顺序：增加显式ID掩码与编译门控；按ID生成profile和换算；覆盖七个ID的独立发现、边界、命令编码与失效回归；完整主机/Keil验证；保留原固件并归档新工件。没有接入的六台电机只做软件验证。
