# Phase 0 已知问题与限制

记录日期：2026-08-12（Asia/Shanghai）

1. USART1 目前只是正式上位机链路候选。PA9/PA10、921600 8N1 尚未写入当前 `.ioc`，UART DMA + IDLE 接收和 PC 双向收发均未实现或验证。
2. J1–J7 仅确认逻辑编号、ESC ID 1–7 和 Master ID 11–17。方向、机械零位、软限位、最大速度/加速度、MIT Kp/Kd、电机量程和外部减速比均未实测，`verified_fields` 因此保持为 0。
3. Phase 0 固件没有电机发送接口，未进行 FDCAN 总线、电机上电、反馈、Bus-Off 恢复或机械动作验收。
4. USB CDC 生成代码和旧 `usb_cdc_transport.c` 仍保留用于工程依赖，但新正式协议未接入 USB，也没有完成当前镜像的 Windows 枚举验证。
5. `User/` 中的旧按键双电机、旧七轴、轨迹和命令代码仍在仓库中作为迁移参考；它们不参与当前 Keil 目标。后续迁移必须逐模块测试，不能直接重新全部加入目标。
6. FreeRTOS `heap_4.c` 仍由中间件工程编译并保留 15,360 字节静态堆区；当前 App 不调用动态分配，架构守卫会检查该约束。
7. Keil 工程的 `<LayerInfo>` 是用户本地元数据，不属于 Phase 0 功能提交；它仍作为未提交工作树差异保留。
8. DH 参数与正逆运动学未进入本阶段。更换机械结构或增加外部减速器后，必须重新建立坐标系、标定和参数来源证据。
