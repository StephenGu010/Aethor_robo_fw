# 设置静载与POS带载试验配额

适用配套v2策略固件及支持`torquePreparationAvailable`的网关。可编辑项是转矩保护退出线，范围3.50～6.24 N·m，静载和POS带载共用；它不是目标转矩，也不是驱动限流。连续超额时间、累计预算、温度门槛不能在此编辑。

1. 启动上位机，点击“连接设备”，选择实际USB CDC串口并“连接并只读查询”。进入“POS 带载测试”或“单轴静载”，选中ID7。
2. 点击“读取远程能力”，确认控制权为“未申请”、没有活动事务。原测试已结束且确认失能后，可用“结束会话／释放控制权”；LCD实际占用时从LCD释放。失能未知则读取原事务，不重复启动。
3. 找到“试验转矩与温度保护 · ID7电机输出轴”，点击“读取转矩保护策略”。
4. 在“试验转矩退出线 N·m”填写3.50～6.24范围内的数值，最多三位小数，或点击3.50、5.46、6.24预设。这一步只改草稿。
5. 电机充分冷却，机械臂及负载独立承托后，勾选“本次确认电机已充分冷却，机械臂与负载独立承托”。页面不会替用户确认现场条件；板端还要求两路温度均≤35℃及低速失能等条件。
6. 若唯一阻塞是“缺少5秒内标准反馈”，点击一次“失能检查并应用试验配额”。它会撤去ID7保持力矩，单次失能采样，再自动核验原门禁并应用所选值。无需切换MIT模式，也无需手动赶在5秒内操作。若板端已允许恢复，则点击一次“冷却后恢复实验配额”；两个按钮不用依次点击。
7. 等待“读回确认 ×× N·m”，核对“上次读取生效边界”为所选实验退出线且显示“实验配额可用”。未确认、被拒或读回不符时，不把草稿当作生效值，不连续重试。
8. 配额应用不会启动电机。只有另行审核本次位移、速度、保持时间及现场条件后，才使用测试的启动入口。

改动数值或重新读取策略会取消本次冷却勾选，须在条件仍满足时重新勾选。刷新、重连或结束会话不会补回已用预算；主控重启后高转矩默认关闭。保护退出也可能撤销配额，恢复前先查原首故障，不能只看账本100%判定实际热量。

模式2待机仍可能只有RID50位置持续更新。配额成功应用后，标准反馈再过期可使“允许恢复”变为否；应分别看“实验配额可用/已授权”与“允许再次恢复”，二者不是同一状态。每次启动仍受板端反馈门禁约束，不能用位置寄存器替代速度、转矩、温度或失能证明。

STOP会取消尚未发送的维护失能及后续配额恢复；已经发送的失能不会撤销，回执等待最长4秒。维护未知锁出现时用“只读核验维护状态”检查，不用旧测试完成结果强行解锁。

保护继续包含：3.50 N·m连续基准、10秒连续超额上限、175.616 (N·m)²·s累计预算、任一路温度超过55℃退出及原有位置/速度/反馈保护。恒定6.24 N·m时满预算理论约6.58秒耗尽，其他条件可能更早退出；这不是厂家允许持续时间。
