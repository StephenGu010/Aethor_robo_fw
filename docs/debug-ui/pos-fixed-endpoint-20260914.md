## 改动与依据

依据本地《DM-S3519-1EC 减速电机（含 DM3520-1EC 驱动器）使用说明书 V1.1》第 6–7、10 页：POS 的 p_des 为目标位置，v_des 为最大绝对速度，驱动器内部完成三环及加减速控制。

本次仅让 LCD 本地、单电机、自包含 POS 动作使用固定终点分支。例如启动位置 20°、相对 +70°，整个运动期间重复下发最终位置 90°和 10°/s 速度上限。目标在执行前由新反馈确定。USB bench POS 的五次轨迹及 MIT 轨迹保留。

## 判定与停止

- 取消 LCD POS 与中间轨迹的 0.5°跟随误差比较。
- 最终位置误差仍须不超过 0.5°；连续新鲜反馈保持 200 ms 才进入结束清理，不能用重复旧样本累计到位时间。反馈中断或离开容差会重新计时。
- 实际位置须在起点到终点区间内，允许两端各 0.5°调试余量，同时仍受配置的绝对位置边界约束。这不是机械标定边界。
- 每次向目标至少推进 0.1°更新进展计时；2秒内无此进展则停止。启动阶段同样采用2秒宽限。该值为本阶段软件调试选择，不是厂家推荐值。
- 总超时沿用行程/速度上限 + 2.2秒。速度是上限，加减速会影响实际耗时；超时后保留记录，不自动延时重试。
- POS帧重发停顿超过50 ms、反馈过期、驱动故障、UI健康异常仍走停止/失能清理。中键STOP仍可抢占运动。
- 本次一并包含前次已授权的 LCD MIT 反馈转矩门限1.0 N·m；它不是硬件限流，也没有新的MIT实机验收。

## LCD 操作

1. 按屏幕文字方向操作，进入“电机列表”，选择电机7。左键返回“系统总览”，选择“申请本地控制”，按中键进入检查/预览，按提示松开后长按800 ms确认。
2. 回到电机7详情，选择底部操作“POS移动”。若当前为MIT模式，POS自包含动作会按现有流程切换并校验POS模式。
3. 编辑页上下键调当前字段，右键在相对角度和速度之间切换。POS角度步长1°；速度默认10°/s、步长1°/s。
4. 首次设置相对 +1°、速度10°/s；按中键查看预览，核对电机号和数值，松开中键，再按住800 ms确认。
5. 执行时中键立即请求STOP；正常结束应显示“动作完成”且失能确认。中/左返回后，本地控制仍保留，每个新动作仍需重新长按确认。
6. 依次测试 -1°、+5°、-5°；这些通过后，在机构确有对应活动空间时再测试 +10°、-10°。记录每次设置、结果、实际位置和失败阶段，不直接从大角度连续重试。
7. 单独用一个小行程验证中键STOP，确认停止结果和失能状态。调试结束在本地控制入口手动释放控制权。

失能后驱动器可能不持续反馈，因此详情页随后显示过期并不自动等于失败；运动中反馈过期会停止。不要把“动作完成”与“最后一个显示数值仍新鲜”混为一项。
