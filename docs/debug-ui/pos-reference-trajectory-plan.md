# 台架 POS 主控参考轨迹实施计划

> 2026-09-11交付更新：本计划的参考轨迹实现、候选归档、刷写回读和电机7有效POS配置已完成，后续取得本地操作/STOP及USB20次重复证据。最新状态见[阶段交付](delivery-status.md)。用户已明确将旧验证电机的转矩/到位问题及物理标定延后到新硬件阶段；下面未勾选的联合实机项保留其未完整通过状态，不再阻塞此次软件交付。历史“待编译/待配置”段落仅描述当时过程。

**目标：** 让单电机 LCD/USB 台架 POS 的位置参考以设定速度平滑推进，并通过自动反馈记录验收；保留既有请求、模式2、STOP和失能语义。

**证据：** 两次±3°试验的发送RAM限速均为0.0087266462rad/s，但反馈在不足半秒内接近目标；标准速度字段仍为-2.799°/s。发送编码正确不等于电调限速行为已验收，不再反复要求用户肉眼确认快慢。

**方案：** 复用主控已有五次时间缩放数学，轨迹时长T=1.875*|位移|/最大参考速度，首点为使能后新鲜位置，每周期更新位置参考，模式2帧速度字段仍携带正的限速。轨迹时间结束且位置到达后才执行原有收尾。数学采样器的MIT枚举只选择五次曲线，不改变电机模式；CAN仍为0x100+ID和两个float。仅改变bench作用域的自包含POS动作，生产机械臂固定端点路径保留。

候选比较：继续扩大电调限速/放宽反馈阈值缺少依据；直接换MIT会偏离先完成POS的目标；主控参考轨迹可自动核验且复用现有控制任务，优先实施。参考速度受限不代表真实瞬时速度必然受限，仍须验证反馈跟随、范围及停止；未通过不开放有效LCD配置。

## 当前验证补充

主机回归通过两方向首点、单调性、参考速度界限和完整多电机轨迹无USB保活的收尾失能流程。旧测试已改为4ms理想跟随仿真；保留STOP、故障和HOLD/DISABLE检查，测试时钟覆盖零位量化短轨迹及五次曲线超时。
