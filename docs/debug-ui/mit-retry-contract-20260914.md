# 电机 7 LCD-MIT 重试合同（2026-09-14）

## 已取得的实机证据

在现有 LCD-POS 固件的 USB 自包含 MIT 链路上测试：Kp=1/Kd=1 保持 1 秒成功；+1° 移动超时。Kp=12/Kd=0.2 的 +1° 仍超时。Kp=24/Kd=0.2、0.5°/s 的 +1° 和 -1° 均完成，并完成 STOP、DISABLE 和 POS_VEL 恢复。日志见 D:/download/TCG/output/mit-retry-20260914/。

completed 表示达到现有 0.5° 到位门限，不是独立角度测量，不表示整机或所有姿态已标定。此次测试起始反馈约 4.49°，不能据此认定旧位置的失败已解决。

## 本次实现范围

- LCD-MIT 构建仅开放电机 7；POS 保留已读回的全协议范围。
- MIT 独立范围：绝对反馈/目标 3.5°..6.5°，相对量不超过 1°，速度不超过 0.5°/s；Kp=24、Kd=0.2 固定，前馈转矩为 0，保持 100..1000 ms。范围是本次调试限制，不是机械软限位标定。
- MIT HOLD/MOVE、POS MOVE、模式切换均在确认后先发送失能，等待本次请求之后的新鲜 disabled 反馈，再验证身份、量程、速度、故障、健康、权限和目标。MIT 相对目标由该新反馈计算，禁止引用编辑阶段的旧位置。
- 获取/退出本地控制本身不产生使能或运动；在已确认失能且无未解决清理时，允许模式 1/2 的旧反馈经过 800 ms 确认。运行仍必须取得新反馈；异常保留既有 STOP 和清理闭环。
- LCD MIT 运行阶段额外拒绝反馈转矩绝对值超过 0.5 N·m、速度超过 20°/s、温度超过 55°C 和非有限反馈，转入失能清理。此软件反馈保护不等于硬件电流限流。
- 不修改电机内部固件、KT/GREF/减速比，不放宽 0.5° 到位门限，不自动增加 Kp。

## 验证要求

主机回归必须覆盖 MIT 过期反馈入队后只产生失能、请求后反馈重新定相对目标、边界/故障/速度拒绝、运行反馈保护以及 POS/MIT 范围隔离。四个构建均须通过。烧录前保存固件和源文件散列、STOP/失能证据；烧录后读回核对并复查电机状态。软件验证与实机验证分别记录。
