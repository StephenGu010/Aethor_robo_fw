## 当前可用操作

1. 上电后松开五向键，等待稳定空闲后再操作。以屏幕文字方向理解上下左右；方向映射已按实物反馈修正。
2. 总览上下选择“电机列表、诊断信息、申请本地控制”，中键或右键进入。主页只有这三项属于设计范围。
3. 电机列表默认选择7，其他ID仍可查看，但未接入的电机不作为本次验收对象。中/右进入详情，左返回。
4. 在电机详情上下切换底部项目。当前LCD-POS选择“POS移动”进入草稿，具体步骤见下文。回退到只读版本时，“位置读值”页显示独立RID0x50、0x51原始float及样本年龄，左返回详情。
5. 在诊断页用中/右/上下切换子页，查看ADC、DMA、CAN/USB及控制时序；左回总览。

当前LCD-POS启动后自动发现电机7，不运行只读版本的两个位置寄存器轮询。回退到只读台架版本后，空闲时交替读取两个位置寄存器；查询不使能、不切模、不写电调Flash。USB动作、STOP、参数发现及队列中的控制工作优先；查询可能暂停。

## 如何判断页面状态

| 显示 | 含义与处理 |
|---|---|
| 详情“状态过期”“反馈过期” | 标准控制反馈不新鲜，不能据旧值判断当前状态。当前POS修正版允许在其他条件满足时进入确认，实际运动前必须发送失能并取得新的无故障失能反馈，再重新计算起点；反馈失败则拒绝运动 |
| 位置读值有数字，详情仍过期 | 两条数据路径独立，可以同时出现；寄存器值不证明使能、速度、转矩、温度或故障状态有效 |
| 位置读值“--” | 尚无该寄存器的可用样本，或该值不是有限数值 |
| 原始读值前标“过期” | 样本年龄达到500ms；值保留供诊断，不表示当前机械位置 |
| “原始值 / 未校验” | 尚未核准机械单位和参考关系，不把数值当作度或弧度，不用于到位判定 |
| “申请本地控制”进入检查页 | 只读目标按设计拒绝授权；当前LCD-POS需进入确认、松开中键后长按约1秒申请，具体拒绝原因以页面为准 |
| 未接电机显示无反馈 | 本台架只有7号，不能据列表有七行推断七台在线 |

此前0xCC的4字节和8字节失能查询均没有得到新反馈，记录保留。不得为了让详情显示“在线”而使能电机或把寄存器回包冒充标准反馈。

## POS/MIT阶段的操作与当前限制

2026-09-14源码调整：LCD-POS仅对电机7开放已核验的协议范围。绝对目标为−PMAX～+PMAX，单次相对位移字段为−2×PMAX～+2×PMAX，速度上限为min(VMAX、电调最大速度参数)。界面换算成°和°/s；相对位移即使在字段范围内，起点加位移仍必须落在绝对目标范围内。发现未完成、范围非有限或无效时不开放配置。协议范围不是机械标定或最高速度实机验收；此前±1°、0.5°/s及−1°～3.5°仅属于旧台架版本。其他电机及MIT配置仍无效。本文首段的烧录哈希是历史记录，不代表此修改已刷入主控。

- 首页选择“申请本地控制”，进入确认后松开中键，再长按约1秒。模式2的正常申请允许标准反馈暂时过期，但不解除失能未确认锁；执行前仍须取得新的失能反馈。
- 详情选择POS移动或MIT保持/移动，进入草稿；上下调整字段，右切字段，中键进入预览，左取消。POS相对角度每次增减1°，速度仍每次增减0.1°/s；超出字段边界时停在边界值。
- 正常松键解锁后，方向键支持持续连加，不再在按满10秒时被误判为卡键。中键及上电一直未松开的按键仍保留10秒卡键检查；采样过期、无效电平和事件溢出仍会中止输入授权。
- 预览要求先松开中键，再连续按住800ms提交；草稿或预览中的值尚未下发电机。
- 执行期间，运动目标的中键按下立即请求STOP，不等待800ms。等待清理终态，区分“反馈已确认失能”和“失能未确认”。
- USB与LCD共享应用控制状态；申请后正常空闲、编辑及动作成功均保留本地控制，直至首页手动“释放本地控制”，不再30秒自动释放。模式2正常失能空闲时允许旧反馈释放所有权；失败清理、失能未确认仍要求新的有效反馈。持有本地控制时远端普通控制请求继续受互斥限制，STOP仍可用。
- UI/Protocol失联、动作失败等异常仍会停止或锁定控制权，需要处理异常后重新申请；持续持有控制权不等于持续使能，每次动作仍独立确认并执行失能收尾。

### “输入或显示异常”后的恢复

先松开按键，等待输入和显示恢复正常，再从首页申请本地控制。模式2在没有待确认失能目标、且已知电机失能、静止、无故障时，允许反馈过期后重新申请；进入确认页后仍须松开中键并重新长按，不自动授权或重发旧动作。

如果原动作清理未确认失能，检查页显示“中键 停止”。按下会对原清理目标发送STOP，实际收到新的失能确认后才能重新申请；没有回包或存在故障时不会解除限制。成功收到的清理确认会保留，不会因之后800ms确认操作超过反馈新鲜期限而再次锁死。仍显示“重新检查”时，该键仅重新评估当前条件并进入确认页；持续输入/显示异常、系统故障、发现不完整或未读结果必须先消除，反复按键不会跳过这些条件。

释放本地控制仍绑定原授权电机；浏览其他ID时应返回原电机。原电机未知、仍使能、故障或失能未确认时，界面会提前显示对应拒绝原因。
- MIT前馈转矩固定为0；HOLD、MOVE和切回POS需分别验收，不能用一次试转证明全部功能。

当前POS使用主控五次参考轨迹。+1°本地动作已从固件确认完成、错误0、详情0及失能，用户确认屏幕一致；−1°用户报告成功，但读取时其完成记录已被后续操作覆盖，保留为用户观察证据。LCD中键停止USB动作已有记录；15:28的LCD动作被USB STOP中断，STOP完成并收到26ms内的新鲜无故障失能反馈，后续无残留控制锁定。证据分别见`motor7-lcd-diagnostics-20260911T072001.json`、`lcd-usb-stop-20260911T152826477.json`及`motor7-lcd-diagnostics-20260911T072907.json`。

外部USB STOP后，原POS取消结果的失能确认字段可能仍为0，而独立STOP结果和之后反馈已确认失能；此显示一致性问题已记录，不能仅凭原取消结果判断电机仍使能。后续已取得LCD本地动作中键停止、USB共享POS路径20次重复及MIT保持/模式恢复成功证据，详见阶段交付索引；MIT移动未到位，完整物理LCD重复和机械标定仍待新硬件复验。原始速度字段受量化影响，反馈位置差分仅作辅助。CAN转矩不是独立力传感器测量，不能作为腕部六轴力/力矩使用。

## 构建、刷写与恢复

四种目标及完整回归命令见[README](README.md)。构建脚本只编译，不自动下载。刷写前应核对本轮目标、保存当前工件和回退证据；LCD-POS用于本地POS验证，LCD-ReadOnly用于只读回退。刷写后以实际Flash回读及对应哈希确认版本，不能仅依赖Keil编译成功。MIT目标尚无本台有效配置，不因编译成功而直接开放运动。

本轮备份目录：`D:\download\TCG\output\register-position-20260911`。原始完整Flash备份为`D:\download\TCG\output\can_id_commissioning_20260909\controller-original-1MiB.bin`，其哈希和各次刷写结果见对应JSON记录。回退时由调试工具使用经核对的备份，不删除或覆盖无关源码。

遇到CAN bus-off、主控复位、UI失去响应或失能未确认时，先保留诊断日志并停止继续发起动作；显示恢复不能替代电机失能反馈。只读目标的中键不发送STOP，需要停止远端动作时使用原USB控制入口。
