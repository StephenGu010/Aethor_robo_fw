# 2026-09-14 LCD 固件发布说明

本发布固定图标界面改造前的最新源码与LCD-MIT固件。固件见[发布目录](../../firmware/2026-09-14/README.md)，尚未包含新图标菜单。四目标同源编译，默认目标关闭LCD，LCD-ReadOnly拒绝所有本地状态变更。

## 最新行为

- LVGL 8.3.11、280×240、五向按键；安装方向映射保持LEFT→DOWN、RIGHT→UP、UP→LEFT、DOWN→RIGHT，中键不变。
- LCD-POS单电机动作发送固定终点和速度上限；LCD-MIT支持本地五次轨迹及有限保持。
- 本地控制正常空闲/成功动作后保留，手动释放；故障或健康失效仍撤权。动作均独立松开后长按800 ms确认，运行中中键立即请求STOP。
- 电机7输出轴坐标兼容比19.2032，LCD相对角度默认/步长1°，速度默认10°/s、步长1°/s。位置范围从发现值换算，不能将最大相对跨度理解为任意位置都能增加该角度。
- 最新LCD输出坐标Kp=80，协议Kp约4.166，Kd=0.2、前馈0。POS/MIT到位按输出轴0.5°，不是旧转子侧0.5°。
- MIT反馈转矩停止门限3.5 Nm；原位置、速度、温度及健康保护保留。这是软件反馈保护，不是硬电流限制或带载性能证明。
- 故障恢复重新检查可通过原目标STOP刷新失能反馈，仍需重新长按申请。结果保留具体保护原因，失能确认与动作结果分开。

## 操作顺序

1. 松开五向键等待就绪；电机列表选07。只有已接入且明确配置的电机可运动。
2. 总览申请本地控制，先松开中键，再按住800 ms。受阻时查看检查页，不跳过失能、静止及反馈门槛。
3. 电机详情用上下选择底部POS移动/MIT保持/MIT移动等动作，中/右进入。
4. 草稿上下调值，右切字段，中预览；核对电机、方向、预计目标、速度后松开并长按800 ms。预计目标只是提示，执行器会重新采集起点。
5. 运行中中键STOP无需长按。收到失能确认后再开展下一动作；退出本地调试时手动释放控制权。
6. 故障后先读原因；重新检查必要时会提交STOP刷新反馈，通过后再申请。未确认失能保持锁定。只读固件通过远端原入口停止，不会因显示而使能电机。
