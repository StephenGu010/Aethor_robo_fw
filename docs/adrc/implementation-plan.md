## 控制器契约

控制单位为输出轴 rad / rad/s、协议名义 N·m、秒；位置、速度与转矩映射分别验证。
历史位置比例 19.2032 不自动应用到速度或转矩；没有转矩传感器时不声称实际转矩标定。
模型分为 controller / plant / validation；仅 controller 生成代码。
控制器采用一阶对象与二阶 ESO，float32、固定 0.004 s、无动态分配。

离散算法：预测 z1p=z1+Ts*z2+b0*Ts*u_sent_previous、z2p=z2；
p=exp(-wo*Ts)，l1=1-p*p，l2=(1-p)^2/Ts；仅新样本执行校正。
kc=(1-exp(-wc*Ts))/Ts；u_raw=(kc*(reference-z1)-z2)/b0。
输出依次经变化率、幅值、MIT 量化；已发送且反解后的指令反馈到下一次预测。
初始化 z1=当前速度、z2=0；运行中不切 PI/LADRC、不改控制或坐标参数。
PI 对照采用同周期、参考斜坡与限制，包含积分抗饱和。

## 首轮实验上限（设计值，不是实测安全能力）

名义辨识转矩约 0.01 N·m 起、受编码步长约束，最大 0.05 N·m；20/40/80 ms 脉冲。
闭环名义转矩最大 0.1 N·m、变化率最大 0.5 N·m/s；参考 0.1/0.2 rad/s，超速 0.3 rad/s。
参考须带斜坡；距离起点不超过 0.35 rad，同时满足当前有效协议位置范围。
正常激励最长 3 s；温度阈值 50°C；反馈超过 8 ms、周期超过 6 ms 进入故障。
100 ms 心跳、300 ms 超时进入停止；PI/LADRC 正常停止确认低速 100 ms 后失能，最长 500 ms。IDENTIFY 到期或提前停止直接请求失能，不继续转矩尾坡，仍需新反馈确认并受 500 ms 期限约束。
故障停止不受正常转矩斜率约束；发送失能、确认失能、不能确认三种状态必须区分。
驱动通信看门狗必须经读取、配置回读与实测验证，目标为失联 100 ms 内退出使能。
模式及必要量程/看门狗只暂存并保存原值，不写永久 Flash；未恢复的配置必须报告。
测量不足、方向异常、重复辨识偏差 >20% 或模型验证失败时，不自动扩大限制。

## 测试与指标

- 算法：复位、正反向、丢样、NaN/Inf、饱和/恢复、转矩斜率。
- MIL：跟踪、等效扰动、b0 的 0.5/1/2 倍、实测及额外 1/2 周期延迟、噪声和量化。
- 代码：与模型逐样本比较，归一化误差 <=1e-4；状态与故障转换一致。
- 主机：选轴隔离、重放不重启、参数非法/未验证拒绝、控制权冲突、停止及恢复。
- 平台：旧帧积压、USB 堵塞、LCD 活动、栈与内存、运行耗时 <1 ms。
- 实机：参考斜坡结束 1 s 内进入 max(5%目标、2量化步长、3静止噪声) 误差带；误差带超过目标20%判为分辨率不足。
- 超调 <=max(10%目标变化、2量化步长)；三次重复通过、稳态不持续饱和、最终失能确认。
- 上板前提：环境、生成代码、编译、回归和实验监督测试全部通过。
