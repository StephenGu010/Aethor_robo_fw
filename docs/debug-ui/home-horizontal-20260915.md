# 系统总览横向导航（2026-09-15）

按用户确认，系统总览的三个图标改为左右循环选择，中键或下键进入。页脚同步显示“左右 选择 中/下 进入”。右键只切换选项，上键无动作；左右长按重复事件继续选择，下键必须产生新的按下事件才进入。

仅首页使用这组按键。电机、诊断等子页面保留上下选择、中/右进入、左返回；数值弹窗和长按确认、运行中STOP逻辑保持原样。物理按键到屏幕文字方向的映射未修改，ID1～7同型号配置和电机控制参数未修改。

回归覆盖左右循环边界、左右重复选择、上键和下键重复事件不进入、三个入口均支持中/下进入且不提交控制请求。原有整页巡航脚本只替换首页对应按键，保留子页面覆盖断言。

实物方向映射回归同步更新为屏幕右键选择、下键进入诊断、左键返回首页、左键切回电机、中键进入。首轮该测试仍使用旧操作序列而失败；更新测试后，完整UI评审回归脚本重新运行通过。工件验证记录保留首轮失败与复跑的来源，生产代码在两次验证之间未变更。
