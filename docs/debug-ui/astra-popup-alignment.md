# 参数弹窗与参考设计对齐

用户指出 Astra 版 B 的参数弹窗与已确认设计存在差异，本次按原设计修正 NUMBER 模板。基于 `2bb39316abdb0900ba735358830a6fe36743016e`；该版本保留在 `archive/lvgl-astra-ui-b1`，原 HEX 在 `firmware/2026-09-14-astra-ui-preview`。A 版和文字版归档也保持不变。

## 对齐范围

| 部位 | 调整前 | 对齐后 |
|---|---|---|
| 弹窗轮廓 | 实际绘制为直角矩形 | 参考坐标 `(17,48)..(263,204)`，圆角半径8、边框2px |
| 标题和数值 | 左对齐，Montserrat 28px数值 | 居中，原设计Noto字体，标题17px、数值30px |
| 滑轨 | 从左向右填充的短条 | 固定细轨`x=39..241`，7×11px方形游标 |
| 辅助文字 | 参数范围和大块反白保存条 | 12px“每步…”与“仅修改草稿”，保存/取消统一在页脚 |
| 父菜单 | 暗灰色连写文字 | 名称左对齐、数值右对齐，选中行和棋盘状遮罩 |
| 页眉 | 电机/动作/数值长标题与中文模拟标记 | `07 / POS 移动`式短标题，模拟渲染右侧独立`SIM` |

这次只调整 POS 的2种、MIT移动的5种、MIT保持的3种数值弹窗。其余79张页面与B1版的RGB像素一致，确认弹窗、执行页和控制模型不在本次修改范围。

布局与字号跟随参考设计；草稿值、游标和参数边界仍来自当前模型，未固定成设计图的示例值。步进文案与现有实现一致：角度1.0°、速度1.0°/s、Kp 0.10、Kd 0.01、时长100ms，边界附近仍由模型裁剪。本次没有调整参数或控制算法。

## 低内存实现

继续使用19个固定界面对象和32KiB LVGL池，不创建截图背景或额外帧缓冲。圆角由有界基本矩形绘制，棋盘遮罩仅修改LVGL当前可写绘图缓冲的裁剪区域；未启用全局复杂绘图。DMA的缓冲所有权由原显示端口保持。

Noto新增稀疏11/12/14/17/30px字库，仅包含弹窗需要的字符，位图合计9291 B。源字体SHA256、OFL版权及字符清单见 `Ui/fonts/POPUP_SOURCE.json`；生成器为 `Ui/fonts/generate_popup_fonts.py`。主机实测池使用10160 B，比B1增加96 B；`DebugUiView`仍为3024 B，未增加页面对象。

## 验证与工件

真实LVGL渲染的89张页面、字形和文字宽高检查通过。新增断言覆盖圆角实际像素、居中字型、完整滑轨、游标两端以及草稿提示；保留1212次共享模板复用、非有限值、只读提示、动画和OOM检查。

字体复现：

```powershell
python Ui/fonts/generate_popup_fonts.py <NotoSansCJKsc-Regular.otf路径> --check
```

完整运行 `tools/verify_debug_ui.ps1 -IncludeKeil`：28项检查通过，四目标均为零错误、零警告，验证期间第一方源码摘要不变。字体位图及清单另外通过固定源字体的逐字复现检查。

三个LCD目标的总RAM均为174464 B，相比B1仅增加40 B；代码及只读数据各增加13160 B，包含新字体及基础绘图代码。LCD-MIT的Code+RO为296936 B。基础无UI目标的代码和RAM不变，DMA缓冲合计26880 B及LVGL池32768 B均保持原布局。

新HEX、SHA256与可移植验证摘要见 [参数弹窗对齐版固件](../../firmware/2026-09-14-astra-popup-preview/README.md)。本次不烧录，所有预览仍是模拟数据；板上显示负载与帧率未作为本次软件验证结论。
