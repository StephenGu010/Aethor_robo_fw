本次只调整速度字段的显示映射：当配置允许10°/s两侧取值时，10°/s位于轨道中央；低于10°/s向左，高于10°/s向右。两侧分别使用归一化的 `distance / (distance + 9)` 曲线，放大常用低速区，压缩远端高速区。滑块是非线性位置提示，准确速度以数字为准。数值步进仍为1°/s，实际速度范围、运动控制和授权条件不变。

速度上限不超过10°/s时保持可用范围的线性显示；固定范围显示中央，不能继续调整。无效或非有限边界沿用不显示滑块的处理。
