# LCD POS / MIT 输出轴角度契约（2026-09-14）

本次将已调试的 7 号 DM-S3519-1EC 的 LCD 相对角度、位置显示和位置边界统一到减速输出轴。POS 与 MIT 默认相对角度均为 1°，上下键均按 1° 加减；默认速度继续为 10°/s，速度步长为 1°/s。

## 证据与适用范围

- `output/pos-fixed-endpoint-20260914/coordinate-pair-20260914T153716692.json`：USB2CAN 读回 Gr=19.2032、PMAX=12.5、VMAX=200；p_m 与打包位置反馈一致，xout 为零，不能作为有效输出轴测量。
- 用户照片与本地厂家二维图纸对应：手动旋转的是黑色外转子，位于减速器输入侧。此前手动“20 多度”不是输出轴角度。
- POS 采样中，打包位置变化率与速度字段相差约一个减速比；本固件对该控制器采用位置为转子弧度、速度为输出轴弧度/秒的兼容契约。厂家通用单位描述不能替代此控制器的实测证据。
- 转换仅用于 bench 配置下的 LCD 7 号电机。USB 原有命令接口和其他电机保留原契约。更换电机、驱动或 Gr 后必须重新核对该兼容常量。

## 实现边界

LCD 输入输出轴相对角度乘 19.2032 后，才进入原有协议命令及目标校验；控制器内部反馈和目标保持原始转子坐标。发布给 LCD 的位置与 POS/MIT 位置边界除以 19.2032。诊断寄存器 p_m/xout 保持原始读数。

POS 下发固定原始终点，速度字段保持输出轴单位；超时时间按输出轴距离计算。MIT 的五次轨迹在原始位置坐标中生成，但规划时长按输出轴距离和速度计算，采样位置导数除以减速比后再编码到速度字段。两模式最终相对位移含义相同，轨迹与总执行时间不要求相同。

PMAX=12.5 时，LCD 绝对位置边界约为 ±37.30°，跨全区间相对跨度约 74.59°；实际允许相对量还取决于当前位置。这是原协议边界的单位换算。原始位置到达容差 0.5°（输出侧约 0.026°）、POS 进展/越界保护、MIT 1 Nm 反馈保护及增益均未放宽。

## 验证与调试

自动测试覆盖 POS/MIT 相同 1° 输入编码、反馈反向换算、模式边界一致、按键跨零加减、POS 固定终点和超时、MIT 轨迹中点位置与速度及规划时长。软件测试和 Flash 回读不代表实际 MIT 输出轴运动已验收。

烧录后重新初始化 7 号电机并获取本地控制，在 POS、MIT 各执行一次相对 +1°、10°/s，观察减速器输出侧。每次动作完成并失能后再切换模式；异常使用 STOP 并保留动作结果。黑色转子对应应旋转约 19.2°，输出轴对应约 1°。MIT 五次轨迹以 10°/s 为峰值速度，不能用两模式完成时间完全相同作为通过条件。
