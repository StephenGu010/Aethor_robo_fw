# 模式2待机试验配额准备修复

后续进展：本文前半部分记录首次只读部署阶段。2026-11-03随后经用户明确确认现场条件，已完成一次失能及5.46 N·m配额应用并读回授权；没有执行使能或运动。详细结果和当前按钮步骤见[配额操作说明](quota-operations.md)。文中的进程号、路径及“尚未实机执行”仅对应首次部署时刻；原始artifacts证据保留在本地，仓库不包含这些现场文件。

2026-11-03。用户要求解除标准反馈过期导致的配额恢复阻塞，使POS带载能够使用已选择的较大转矩。本轮没有使能、失能、恢复实机配额或执行运动。

## 根因与修复

模式2待机通过RID50持续获取位置，不能据此证明实测速度、转矩、温度或失能状态；当前驱动器对待机CC读取没有经验证的标准反馈响应。配额恢复正确要求5秒内标准反馈，原上位机缺少显式准备入口。

新增“失能检查并应用试验配额”：用户确认独立承托与充分冷却后，仅在v2策略唯一阻塞为32、同一启动号和坐标基准、空闲控制权时，允许单次ID7失能。失能完成后重新查询板端策略，只有原有门禁全部通过，才使用新令牌一次应用所选值并读回核验。不会使能、切换模式或启动测试。不能仅凭completed回执或旧缓存确认新反馈；前读缺失而后读通过才允许继续。

STOP取消尚未发送的维护失能及后续恢复；已发送的失能不会撤销，既有事务回执等待最长4秒。导航、断连、启动号变化均终止后续动作；失能或恢复结果未知保留独立维护锁，旧测试终态不能解除该锁。提供只读维护核验入口，不自动重试。

单轴静载和POS带载共用3.50～6.24 N·m试验退出线，单位为电机输出轴。连续超额最多10秒、累计175.616 (N·m)²·s、55℃退出、恢复温度两路均≤35℃等保护保持不变。6.24 N·m恒定超额按满配额理论约6.58秒耗尽，不保证能持续10秒。
