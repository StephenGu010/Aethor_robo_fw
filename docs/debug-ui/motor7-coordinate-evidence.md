# 电机7坐标与速度证据核对

日期：2026-09-11。此记录支持P6/P7的后续台架配置决定；不修改坐标换算、减速比、停止阈值或有效配置标志。

## 文档与历史回包

型号手册为`S3519/DM-S3519-1EC/说明书/DM-S3519-1EC减速电机（含DM3520-1EC驱动器）使用说明书V1.1.pdf`（相对TCG根目录）。反馈说明明确位置rad、速度rad/s及转矩Nm均指减速后的输出轴；POS_VEL帧为0x100+ID及两个小端float，速度字段定义为最高速度限制。

同一本手册给出的齿轮减速比为3591/187，约19.2。2026-09-09保存的`output/can_id_commissioning_20260909/motor7-health-parameters.json`中RID0x14原始应答数据为`27 A0 99 41`，记录值19.2032，与该型号手册相符。它是历史读回，本轮未重新读取Gr。不得把其他型号或机械臂末端附加传动比直接套入这台电机的反馈换算。

手册POS_VEL例子存在内部不一致：文字写3.14159rad、最高10rad/s，但示例8字节为`CF 0F 49 40 00 00 20 42`。按小端float实际解码为3.14158988和40.0。当前`App/Motor/s3519_codec.c`直接按小端编码调用方传入的两个float，没有复制这段示例常量。因此该文档错误应记录，不能直接当作当前速度异常的根因。

## 实际异常仍未关闭

原始动作`1709055818 bench move 7 position=60 speed=0.5`的日志为`output/can_id_commissioning_20260909/controller-motor7-60deg-165554.json`。约3125ms处反馈26.239度、转矩0.637Nm，超过当次0.6Nm的PC停止门限后取消，最终失能确认成功；没有达到60度。

位置增量/时间与命令限速不一致，速度反馈却仍多为-2.799度/秒。用户观察黑色部件转动约20多度，但该部件尚未与输出轴身份及角度参考一一对应。文档定义、齿轮比和肉眼观察不足以证明驱动实际报告的是哪层坐标，也不能据此乘除一个比例使测试看起来通过。

当前新增的0x50/0x51读取只提供原始float及年龄。失能时它们能持续回包，不代表运动中的标准速度和位置语义已经验证。

型号手册第3/4页明确把配套4Pin异面线列为编码器线，CAN线为2Pin，三相线为3Pin。这与用户早前对“四根线应该是CAN口”的描述需要实物核对；不能仅凭CAN通信正常推断电机至驱动器的编码器连接正确，也不能仅凭这段描述判定现场确实接错。复核时按接口功能及配套线序，不把四芯编码器接口接入CAN分配口。

## 仍需的单电机验证

1. 明确实际输出轴及独立可观察的参考标记；区分电机外壳、转子和减速输出。
2. 在当前接线及电调版本下，记录一次明确的POS指令原始CAN字节、运动中的标准反馈和独立输出轴观察，核对目标、速度、方向和参考复位行为。
3. 保留STOP/DISABLE及失能确认；未查明差异前，不填写有效POS台架配置，不以位置寄存器样本替代安全门禁。
4. POS通过后再单独确定MIT增益和期限，完成HOLD/MOVE、切模及各阶段STOP记录。

用户此前允许先推进LCD主线；本问题依然属于P6/P7未完成项，不能因暂缓调查而标记为已解决。
