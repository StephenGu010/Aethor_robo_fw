# 单轴静载和POS带载统一法兰端显示

用户明确要求这两页的角度和速度都换算法兰端。本次仅更新上位机，不执行电机动作、不修改固件保护。

ID7已核实转子/输出轴比19.2032、转子/法兰总比44.8；输出轴/法兰比为44.8/19.2032≈2.332945。44.8已经是总比，不再与19.2032叠乘。

显示法兰度/度每秒＝输出轴对应值÷2.332945；输入法兰度/度每秒后转回输出轴rad/rad/s发送原协议。控制草稿始终保存输出轴单位，能力范围及保护继续按原坐标校验。10°法兰对应输出轴约23.329445°。

实时静载和POS带载页面使用法兰参数标签、审核值和反馈读数；手动调试保留原输出轴口径。静载保持当前位置，不额外新增定位动作。Kp/Kd/前馈仍明确标注输出轴口径。

离线静载页面的观察角度、误差、保护线与预算速度按法兰显示，策略判断和记录原坐标不变；旧记录不改写坐标身份。其他轴没有确认法兰映射时不套用ID7比例。

验证覆盖双向角度/速度换算、负方向、零与NaN、法兰参数仅反向转换一次、审核值一致、原协议坐标与范围保留、静载反馈、手动页面不变以及离线静载观察。

验收结果（2026-10-27）：54项主单元测试、29项浏览器测试通过；补齐离线POS旧记录预览后，相关7项单元测试、14项浏览器回归及TypeScript/生产构建通过。离线POS按记录原坐标投影到法兰，保留原记录身份。
