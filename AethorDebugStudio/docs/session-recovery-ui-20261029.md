# 会话结束和实验配额说明：上位机更新

## 已完成

- 在单轴静载、POS带载和手动调试的“远程参数与单轴控制”顶部增加独立的“结束会话／释放控制权”按钮。
- 按钮只读取能力、核对原事务终态及失能证明、重新核对会话身份、提交一次release并复核实际控制权；不使用运动参数草稿，不使能、试动、预检或恢复实验配额。
- 活动、失能未确认、结果未知或LCD/本地占用时不抢占。释放已完成但当前控制权未核实，自动和手动恢复仍保持锁定；待核实上下文跨页面保存。
- owner=1改为“LCD / 本地保护占用”。现有协议将LCD控制、本地故障锁定等合并到该值，无法仅凭owner=1确定LCD正在操作。页面提供LCD控制准备页恢复/释放指引。
- 标准反馈缺失不再与“POS 1 / 静载 1”混淆：后者仅为固件功能能力，寄存器位置不能授予运动资格。
- 配额区显示上次读取实际采用3.5还是5.46 N·m保护线、原因码、恢复条件和步骤。原因5保留“反馈/服务时序异常或其他故障统一撤销”的歧义，不冒充测试首故障。撤销后账本记满不等于实际运行满10秒。
- 恢复仍需板端允许、新维护令牌和本次人工冷却/承托声明。5秒是反馈有效期而非冷却时间。未自动切换模式、预检或恢复额度。

## 当前使用

1. 测试失败后先读取原事务终态。失能未确认时仅继续只读恢复，不结束会话。
2. 确认失能后点击顶部结束按钮。成功后控制权显示“未申请”。
3. 若显示LCD / 本地保护占用，按LCD控制准备页原有提示恢复并释放；上位机不强行接管。
4. 实验配额请按黄色面板的四步说明单独处理。模式2缺少标准反馈时，失能预检入口仅MIT模式开放；模式切换和预检须用户另行选择，软件不会自动执行。
