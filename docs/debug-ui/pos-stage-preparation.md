4. 保留验证记录及回退镜像。LCD-POS 产物只用于构建检查，不作为运动验收。

此前 motor7-test-152545.json 中 passed=false，试转触发0.5 Nm保守阈值，清理后禁用已确认。这组动作尚未通过，不设置 DebugUiMotorProfile.pos_valid=1；MIT 保持无效。绝对位置窗口、动作超时、运动中的力矩停止约束仍须结合台架证据明确，不能以 PMAX/VMAX 编码范围替代。
