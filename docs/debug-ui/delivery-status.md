## 延后问题及使用限制

1. **旧台架转矩/到位问题：延后到新电机适配与标定阶段。**旧电机没有独立力传感器；CAN转矩是驱动器提供的反馈，不能当作独立实测轴转矩，更不能替代腕部六轴力/力矩。POS约0.5Nm主机阈值事件和MIT未到位保留原始记录。用户批准延后，不等于已解决。
2. **保留运行保护。**不放宽现有范围、超时、反馈有效性、停止和失能确认检查，不为通过验收修改成功条件。旧台架不继续自动重复试转。
3. **结果显示一致性：延后。**USB STOP可能已独立确认失能，而原动作取消结果仍保留未确认字段；以独立STOP及新鲜反馈核对，不伪造原结果。
4. **健康撤权偶发事件：保留诊断。**最新版本增加首次健康故障快照；未复现不代表根因已消除。
5. **物理验收：新硬件再做。**真实输出角度/方向/速度标定、全套物理LCD重复操作、接线测量、SPI及最坏工况延迟尚未全部完成。

## 迁移顺序

1. 新电机到位后先确认协议、模式、ID、输出侧单位、减速比、方向、零点与反馈范围；编解码和配置适配放在Motor层，UI继续通过统一应用执行者发请求。
2. 默认保持新电机POS/MIT配置无效。完成只读发现、STOP/失能验证及保守参数标定后逐项开放；不复制旧电机7的范围与增益作为新电机已验证参数。
3. 六轴传感器先确定接口和数据格式，独立采集Fx/Fy/Fz（N）、Mx/My/Mz（Nm），同时提供时间戳、坐标系、有效性、超时和过载状态。型号未定前不编写猜测协议。
4. 空载调零、偏置和重力补偿、传感器到工具坐标变换各自验收。初期仅显示记录，后续明确保护策略后再接入控制；禁止拿电机估算转矩填充六轴测量字段。
5. 在新硬件上重跑POS与MIT、双端STOP、失能和物理LCD重复操作，再开展力反馈控制。多轴联动和力控性能不属于此次单电机软件交付的已通过项。
