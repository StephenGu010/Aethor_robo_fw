# 单电机接线阶段与调参记录规则

本文件是实施步骤，不是实机验收记录。软件测试夹具、模型默认值和历史其他电机数据都不能作为当前电机的运行资格。

## 何时接线和供电

| 阶段 | 所需连接 | 供电与动作 |
| --- | --- | --- |
| 模型构建、MIL、生成 C、主机测试、Keil 编译 | 无需硬件 | 电机不供电 |
| 烧录已验证实验固件 | 按现有控制板烧录方式连接下载器 | 控制板需要正常逻辑供电；电机功率电源保持关闭 |
| 身份、参数与反馈检查 | 只接本次单电机，控制板 CAN 与上位机 USB | 检查接线和台架固定后，按该电机手册额定范围供电；保持驱动失能 |
| 有界辨识、空载速度试验 | 同上，具备立即切断功率电源的条件 | 每次显式运行一个有限时长试验；每次结束确认实际失能 |

接线时核对电源极性、CAN_H/CAN_L、参考地、终端电阻和编号。供电电压/限流值应取实际电机铭牌、供电设备及台架能力的交集，不从其他型号或历史实验推定。电机必须固定，输出轴运动范围内无连接负载或碰撞物。软件 STOP 的实际执行依赖控制板、总线和驱动，不能替代台架断电手段。

## 建立当前硬件的资格证据

1. 保存电机 ID、驱动硬件/固件版本、控制板固件哈希与接线照片的文件路径。明确实际接入的是哪一个轴，禁止以“其他六轴无反馈”为由扩大目标掩码。
2. 读取并保存当前模式、位置/速度/转矩编码量程与通信看门狗值。必要的临时配置必须回读；实验结束恢复原值，不写永久 Flash。
3. 核对位置和速度坐标。现有项目对 motor 7 的历史位置采用 19.2032 比例，这不是当前电机自动通过的证据。位置、速度、名义转矩三种映射分别记录；不能统一除以减速比。
4. 在失能且静止时记录速度噪声、编码量化步长、反馈时间戳、更新间隔、丢样与最大时延。只有实际更新频率和延迟支持 4 ms 控制方案，才继续；否则修改采样周期并重新生成、仿真与测试。
5. 实测驱动失联后的退出使能行为，目标不超过 100 ms；同时确认 CAN 发送失败、反馈超时和主控停止更新的处理。未完成这些验证时不得进行自动转矩辨识。
6. 将证据绑定当前电机、坐标、量程、固件与实验参数。USB 参数命令不接受 `verified=1` 一类自我声明；可信资格由集成层根据实际证据提供。

## 辨识 b0：先辨识，再选择带宽

速度模型采用 `dω/dt = b0 * u + f`，其中 u 是经过限制、MIT 编码再反解的名义转矩，ω 是已核实的输出轴速度。此处 b0 的单位是 `(rad/s²)/(名义 N·m)`。没有转矩传感器时，它是本套指令接口下的有效增益，不等同于独立测得的机械转动惯量倒数。

从约 0.01 N·m、20 ms 的单次脉冲开始，必须先核对编码量化后实际指令是否为零。每次仅改变一个变量，按需要使用 40/80 ms，名义幅值上限 0.05 N·m；测量不足时不能自动加大幅值突破限制。先用正负小脉冲核对方向，异常立即退出。使能等待会占用有限运行时间，分析时只使用日志中真正发送了激励的区间。

有转矩斜率限制时，不能把脉冲当作理想矩形。使用实际发送序列计算 `Δω ≈ b0 * Σ(u_sent * Ts) + ∫f dt`。建议在低速有效区间联合拟合 b0 与摩擦/偏置项，比较同速度附近的正反向数据，减小摩擦偏置；不要对量化速度直接作逐点差分后取峰值。

20/40/80 ms 是从 RUN 接受时刻计算的激励截止期限。到期或提前 STOP 后直接请求驱动失能，不再施加限斜率的转矩尾坡；MIT 编码的“零”也不能视为物理零。该期限约束主控发出的请求，实际断矩时刻仍取决于总线与驱动，应单独测量。失能必须由请求之后的新反馈确认，500 ms 未确认则保留停止超时故障；辨识拟合窗口截止于最后一次有效激励，不把失能后的滑行当成持续转矩响应。

最少保留三组重复数据和一组未参与拟合的验证数据。若速度变化不能明显超过量化与静止噪声，或 b0 方向错误、重复偏差超过 20%，判为尚不可辨识。验证数据的预测误差应低于计划规定的 `max(10%速度变化范围, 3倍静止噪声)`；不满足则返回检查延迟、坐标、实际指令与模型阶次。

## LADRC 调参顺序

1. 冻结采样周期、坐标映射、限幅/斜率、b0、测试参考斜坡以及停止门槛。先验证 b0 正号，不用改变符号的办法掩盖接线或坐标错误。
2. 在仿真中从保守控制带宽 wc 开始。以 `wo≈3wc` 作为扫参起点而非保证值，联合扫描 b0 的 0.5/1/2 倍、实测延迟和额外 1/2 个采样周期、量化与噪声。单位都是 rad/s，不是 Hz。
3. 先固定 wo 调 wc，观察跟踪和持续饱和；再固定 wc 调 wo，观察扰动恢复、z2 和指令抖动。更高 wo 会更强地放大噪声，不能靠持续提高观察器带宽补偿低更新率。
4. 只有通过全部软件检查并形成对应参数哈希后，才做参考 0.1 rad/s 的首轮空载试验，再评估 0.2 rad/s；每次运行最长 3 s。运行过程中不切算法、不修改 b0/wc/wo 和坐标。
5. 每次结束后读取冻结日志，检查峰值速度、行程、温度、发送失败、反馈年龄、饱和比例、停止时长和实际失能证据。参数改变后重跑对应仿真，并保存新参数版本，不能覆盖旧实验记录。

控制器采用离散参数 `p=exp(-wo*Ts)`、`l1=1-p²`、`l2=(1-p)²/Ts`，以及 `kc=(1-exp(-wc*Ts))/Ts`。ESO 预测使用上一周期实际发送的指令；同一反馈样本不能被重复校正。预测校正离散结构不能直接填入连续 ESO 的 `2wo/wo²` 系数。

## PI 对照与验收

PI 与 LADRC 使用相同参考斜坡、执行器限制、编码量程、记录频率和试验时长。PI 也要调参并处理积分饱和；相同的参数名 wc 不证明两者具有相同闭环带宽。先分别达到稳定可用，再比较同一工况，不预设 ADRC 必然更好。

按实施计划检查：斜坡结束后 1 s 内进入 `max(5%目标, 2量化步长, 3静止噪声)` 误差带；误差带超过目标的 20% 则报告分辨率不足。超调阈值为 `max(10%目标变化, 2量化步长)`，连续三次重复通过，稳态不持续饱和，最后确认实际失能。

当前是固定空载单电机方案。模型中的负载阶跃可用于仿真抗扰比较；在没有可重复施加/测量负载的装置前，空载实测结果只能证明空载速度表现，不能证明真实负载扰动恢复优势。

## 每次试验必须保存的内容

- 日期、试验编号、电机与板卡身份、固件/模型/生成代码/参数哈希。
- 运行前后的模式、量程、看门狗原值/实验值/恢复回读值。
- 每周期时间、反馈时间、参考、位置、速度、原始转矩、受限转矩、已发送转矩、z1/z2、状态与故障。
- 测量来源、是否仿真、是否失能确认、日志溢出计数、异常中止原因。
- 结果与未满足项。轨迹缺失、时间异常或恢复未确认时，不把本次登记为通过。
