## 判断依据

1. 网关固定只读`result`回复、板端静载统计和永久首故障记录的事务身份一致。报告的first_exit_latched=1、first_exit_phase=HOLD，排除了把后续清理结果误当首故障。
2. 首故障时目标原生位置-15.695556640625 rad，反馈-15.351806640625 rad。除以本次冻结的内部位置比19.20319938659668，误差约1.025632°。生产代码在该作用域先检查此误差是否超过1°，满足此次OUT_OF_RANGE触发条件。
3. 保持报告在违规反馈被保护处理前计入该反馈，峰值误差1.025635°与首故障独立计算一致。转矩峰值2.820513 N·m低于3.5 N·m基线，也低于5.46 N·m实验边界；本次没有验证短时过载窗口。
4. 首故障时驱动状态1（已使能）；8 ms后的终态记录为状态0，并取得板端失能确认。这只说明本次失能确认链路完成，不将驱动失能等同于机械臂已停稳。
5. 故障后`ui torque`返回authorized=0、used=175.616、reason=5。当前实现对其他保护导致的退出也会撤销剩余配额，并在无既有配额原因时填入FEEDBACK；因此这条后续状态不能推翻永久首故障，也不能证明本次首故障是反馈丢失或已消耗10秒超额窗口。测试开始前是否恢复实验配额，未从本次终态推断。

本次已证实的位置偏离需要结合负载保持能力、Kp/Kd与前馈设置进一步分析；未据此修改保护边界、控制参数或固件，也未进行新试动。
