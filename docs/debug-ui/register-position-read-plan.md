## 文档依据及限制

`D:\download\TCG\S3519\DM-S3519-1EC\说明书\DM-S3519-1EC减速电机（含DM3520-1EC驱动器）使用说明书V1.1.pdf`：

- 第16页：0x7FF标准CAN参数读取，`CANID_L CANID_H 33 RID`，响应在Master ID上返回同一RID及4字节小端数据。
- 第19页：0x50（80）p_m为电机当前位置，0x51（81）xout为输出轴位置，均为只读float。
- 第18页：hw_ver标为保留，不据0值判断硬件代际。
- 手册未给出sw_ver原始整数到发布版本的明确解码规则，不猜测日期。

2026-09-09的 `motor7-health-parameters.json` 已保存0x50和0x51的成功原始回包。该历史记录支持采用参数读路径，但不证明当前实时查询频率、位置单位或精度已验收。上一轮失能状态0xCC查询4/8字节均无新回包，本轮不重复该试验。

## 实现合同

1. 增加独立的只读位置请求/响应状态，RID只允许0x50、0x51及版本核对项；由ArmControlTask现有CAN调度发出，禁止UiTask直接发帧。
2. 每次只允许一个未完成请求，校验Master ID、ESC ID、0x33操作码、RID、长度和有限float。超时记录失败，不补造数据；晚到响应和模式操作按已有隔离机制处理。
3. 先串行读取两项并记录原始值、独立时间戳及超时，再决定周期。执行命令、STOP和参数发现优先；未确认单位前界面标为原始寄存器值。
4. LCD位置寄存器读值与标准反馈分开显示。成功读取0x51不得刷新速度、力矩、温度、故障或使能状态，不得满足本地运动准入或到位条件。
5. 自动测试错误ID/RID、超时、晚到包、NaN、忙时让行、只读权限和生产配置；实机通过连续采样后才启用周期刷新。
