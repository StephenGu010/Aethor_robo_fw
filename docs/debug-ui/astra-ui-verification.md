## 操作路径

首页有电机、诊断、本地控制三个 Tile。电机列表进入六项操作列表：详情、POS 移动、MIT 移动、MIT 保持、模式、恢复。诊断先选择类别，再查看只读数据。列表到头停止；首页循环；左键返回父页并恢复原焦点与滚动位置。

POS、MIT 移动和 MIT 保持先进入参数列表，中键或右键打开对应数值弹窗。上下修改，中键保存该字段，左键取消该字段，右键不触发动作。参数列表左键放弃整份草稿；选择预览后进入确认。MIT 保持只有 Kp、Kd、时长，位移为零。

模式切换、清故障、失能、申请和释放本地控制均经过确认。确认必须先松键，再连续按住中键 800 ms；保存字段不会直接提交。执行期间中键优先请求 STOP。结果与故障返回电机操作列表；失能未确认可进入控制检查，但不会因此自动解除限制。

## 数据与权限边界

角度、速度、转矩仍是电机输出轴单位，范围由现有 Profile 和发现结果提供。显示区分当前、未知与带年龄的上次反馈；模式以实际读回结果为准。浏览菜单不改变使能或控制权。LCD-ReadOnly 不提交本地请求，包括 STOP。活动目标来自执行/清理状态，不能被当前浏览电机替换。

物理按键继续按文字方向映射：LEFT→屏幕下、RIGHT→屏幕上、UP→屏幕左、DOWN→屏幕右，中键不变。

## 验证记录

真实 LVGL 软件栅格器已输出 89 张不同的 280×240 页面，使用生产双 DMA 缓冲显示端口与模拟 SPI 完成回调。文件位于 `Tests/ui/artifacts-astra`，对应场景见 `Tests/ui/astra_ui_scenarios.inc` 和 `ui_render_smoke.c`。主机数据显式标记为模拟，M07 的示例数值不是修改后的实际 Profile。

主机回归验证了全部字形、文字宽高、弹窗背景文字、1212 次模板更新无保留分配增长、OOM 本地退出和 DMA 缓冲所有权。新增测试覆盖非有限反馈显示未知、结果按钮与实际返回条件一致、只读检查页无 STOP 提示，以及 Tile 动画启动、不重启、完成和活动/输入异常取消。

Tile 使用 140 ms 有界动画，位置至多每 20 ms 更新；列表采用即时反白和滚动条，避免为列表滑动增加中间对象或延迟导航。LVGL 刷新周期为 20 ms；快照服务和 STOP 路径继续先于绘图，显示等待期间继续处理输入。以上周期是软件配置，板上帧率、SPI 负载与实时性尚未实测。

独立审查发现并修复了失效草稿 NOTICE 循环、右键进入确认后首次中键长按无效、取消恢复确认过早清锁、结果提示与实际去向不一致，以及非有限历史位置显示问题。恢复锁定由真实清理证据解除，打开或取消对话框不解除。
